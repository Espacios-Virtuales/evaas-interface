# EVAAS Interface · Documentation

Este portal organiza la memoria operacional del proyecto EVAAS Interface.

## Lectura recomendada

```txt
Vision
↓
Arquitectura
↓
Politicas
↓
Fases
↓
Contratos
↓
Operacion
```

## Indice

- `architecture/`: mapa estructural del frontend y limites del dashboard.
- `policies/`: reglas de roles, acceso y separacion cliente/admin.
- `phases/`: resumen cronologico de fases y planes por etapa.
- `flows/`: flujos funcionales transversales, como autenticacion.
- `contracts/`: contratos API y mapa frontend/backend.
- `frontend/`: decisiones y pantallas del cliente Angular.
- `backend/`: notas backend cuando existan desde EVAAS Core o integraciones.
- `operations/`: guias operativas, ejecucion local, despliegue o soporte.
- `roadmap/`: planificacion futura y secuencia de producto.
- `decisions/`: decisiones arquitectonicas puntuales.
- `audits/`: diagnosticos, riesgos y recomendaciones.
- `legacy/`: documentos preservados por continuidad historica.

## Convencion de nombres

Se mantiene `kebab-case.md` para preservar continuidad con los documentos existentes y evitar renombres innecesarios. Los nombres se normalizan principalmente por ubicacion semantica.
